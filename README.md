## Primary insight

**Failed-Adjudication Class (FAC).** A named discriminator — an instrument, a replication, an algorithm — was publicly predicted to *settle* a tension. After it ran, two or more live camps remained. Both camps cite the same upgrade as evidence.

This is not TAC (missing converter, named dark).
This is not NCR (named cause is real but the residual was never closed).
This is not discriminator-*absence* (NCR already owns "no discriminator exists").
This is discriminator-*impotence*: the discriminator was deployed and licensed both sides.

**Falsification rule.** If the next independent observable is predicted differently by the two camps, is run, and kills one camp, FAC is wrong for that case. If a named "this will settle it" upgrade stays cited by both camps after it runs, FAC holds for that case. Scores are a classification heuristic. They are not measurements of nature.

**Adjacent prior art (logged, not hidden).** Duhem (1906) / Quine: there is no crucial experiment. Collins: experimenter's regress. The remaining gap is operational, not philosophical: a scored census of 2024–2026 cases where a *specific upgrade was publicly named as the settler* and then split the field. Novelty is therefore capped at 0.448 (ceiling was 0.68). Claiming "underdetermination exists" would be a closed row.
